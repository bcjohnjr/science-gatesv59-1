# Upload instructions

Recommended repository: `bcjohnjr/Planetary-Restoration-Model-59.1`.

1. Create a new branch such as `science-gates-v59-1` so the current branch remains preserved.
2. Extract this ZIP locally.
3. Upload the **contents of the extracted folder** to the repository root. Do not upload the ZIP itself as the repository contents.
4. Commit the files.
5. Open the repository's **Actions** tab.
6. Select **V59.1 scientific gates — FaIR + Hector**.
7. Choose **Run workflow** on the new branch.
8. Leave `commit_results` off for the first run. Download and inspect the combined Actions artifact first.
9. If the outputs pass review, rerun with `commit_results` enabled or commit the reviewed outputs manually.

The model version remains V59.1 until the new experiment results justify a scientific revision.
